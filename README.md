# FERES — прототип сайта feres.ru

Рабочий прототип (HTML/CSS/JS) нового сайта бренда FERES, ООО «ФЕДЕРАЛ РЕЗЕРВ».
Сделан по брифу `FERES_prompt_v3_final.md` и данным точек продаж из `FERES_Tochki_prodazh_ADMIN_PANEL.xlsx`.

**Собран весь сайт Фазы 1** — 12 страниц, единая дизайн-система, реальные данные там, где они есть.

---

## Как посмотреть

```bash
python -m http.server 8899 --directory "C:\Users\user\Desktop\Сайт FERES\site"
```

Затем открыть `http://localhost:8899/index.html` и переходить по меню — все разделы кликабельны и ведут на реальные страницы, 404 нигде нет.

Просто открыть `index.html` двойным кликом тоже можно, но подсказки поиска и фильтры каталога/базы знаний не заработают: браузер блокирует `fetch` к локальному JSON по протоколу `file://`.

│   ├── js/product.js       Переключение фото в галерее карточки товара

│   │                       latin+cyrillic, 15–17 КБ на начертание
│   └── img/
│       ├── brand/          Логотипы в трёх цветах + фавиконки (из фирменного пакета)
│       ├── products/       Фото товаров с вырезанным фоном. Страницы используют
│       │                   WebP (~2 МБ суммарно), PNG остаются мастер-файлами
│       │                   с прозрачностью — для дизайнера и для загрузки в 1С/Битрикс
│       └── atmo/           Тёмные студийные кадры для фона героя и базы знаний
└── data/
    ├── products.json       10 товаров: артикул, группа, применяемость, фото, галерея
    ├── locations.json      20 точек продаж из Excel — источник раздела «Где купить»

Разметку каждой внутренней страницы (кроме index.html и ui-kit.html) собирает свой Python-генератор:
он один раз читает шапку/подвал из `index.html` и данные из `data/*.json`, поэтому шапка, подвал и
карточки товаров везде идентичны и правятся в одном месте. Генераторы не входят в `site/` (это
build-инструменты, не часть сайта) — при следующей итерации отдам их вместе с проектом по запросу.

## Герой на весь экран

По вашей правке главная страница открывается настоящей фотографией во весь первый экран — реальный
студийный кадр деталей FERES (гильзы, поршни, клапана, кольца), а не рендер или сток. Приём подачи —
как у sevi.ru (одобренный референс из брифа): тег локации сверху, крупный заголовок у нижней кромки,
CTA-планка на всю ширину внизу с тремя действиями. Палитра и материал — свои, чёрно-песочные, как
требует бриф.

Фон затемняется сильнее слева-снизу (под текст) и слабее в остальной части — фото видно, но заголовок
читается в любом месте. Проверено на 1920 / 1440 / 820 / 390 px.

## Карта в разделе «Где купить»

Карта нарисована на сайте, без внешних сервисов и API-ключей: контур России из Natural Earth
(российская точка зрения — Крым и Калининград на месте), проекция Альберса, упрощение
Дугласа — Пекера. Файл `data/map-russia.json` весит 23 КБ, грузится мгновенно и работает офлайн.

Маркеры кликабельны и связаны со списком: клик по городу фильтрует точки, кнопки «Оптовики / Розница / СТО»
подсвечивают только нужные города, а «Показать на карте» из карточки поднимает к нужному маркеру.
Все 20 адресов лежат в HTML статически — поисковики их видят без JavaScript.

Когда появятся точные координаты адресов, карту можно оставить как есть (поменяв только координаты
в `locations.json`) либо заменить на Яндекс.Карты — разметка и фильтры от этого не зависят.

## Дизайн-решения (что и почему)

**Палитра.** Чёрный `#000000`, песочный `#DDCBA4`, серый `#97999B` — строго по брендбуку. Добавлены производные графитовые фоны `#0A0A0B → #1F1F23`: они дают тёмной теме глубину и слои, не вводя новых цветов. Песочный работает только как цвет действия и смысловых акцентов.

**Типографика.** PF Din Text Cond Pro во всех ролях: Bold — заголовки в верхнем регистре, Medium — подписи и артикулы, Regular — текст, Light — лид-абзацы. Узкий гротеск даёт «инженерную» плотность и отличает сайт от конкурентов на стандартных шрифтах.

**Фирменный эффект «лак».** Несколько приёмов, все на CSS/чистом JS без библиотек:
1. `.lac` — песочный блик, следующий за курсором (координаты пишутся в CSS-переменные одним обработчиком через `requestAnimationFrame`);
2. `.sheen` — пробег светового блика по кнопке или плитке при наведении;
3. медленный световой проход по фото-герою — как отражение на кузове;
4. `.magnet` — кнопки финального экрана тянутся к курсору;
5. «занавес» — подвал закреплён под страницей и открывается при скролле, как поднимающийся занавес (на мобильных и при `prefers-reduced-motion` — обычный подвал).

**Структурный элемент — «шкала».** Разделитель под подписью каждого раздела построен как шкала измерительного инструмента: деления через 8 px, крупные через 40 px. Это отсылка к допускам и точности, а не абстрактный декор.

**Конверсия.** С любого экрана «Стать партнёром» и «Где купить» в один клик: в шапке, в герое, в развилке аудиторий, в карточке товара, на финальном экране каждой страницы. Цены не показываются нигде — вместо цены путь к покупке (карточка товара так и говорит: «Ваша цена — в личном кабинете»).

**Честность демо-контента.** Там, где данных нет, страница либо явно об этом говорит (`.demo-note` на каталоге и в разделе «Производство»), либо блок просто не выводится — как того требует бриф для карточки товара («блоки без данных не рендерятся»). Реквизиты, сроки и цифры, которых нет в исходниках, никогда не выдуманы — везде честное «уточняется».

**Ориентир качества — sevi.ru** (одобренный руководством референс): полноэкранное фото героя, тег локации, CTA-планка на всю ширину. FERES решён в своей палитре и со своим характером — тёмный «лак» вместо светлого минимализма.

## Демо-данные, которые нельзя публиковать как есть

`data/products.json` помечен `"demo": true`. Артикулы и группы взяты с реальной упаковки и из фотобанка, а применяемость по моделям и названия — предварительные: они восстановлены по номеру детали и требуют проверки по 1С. Новости, статьи базы знаний и текст «Производство» — заглушки в тоне бренда, честно помеченные там, где это важно для юридической аккуратности (реквизиты, фото цеха).
