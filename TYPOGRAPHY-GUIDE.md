# Типографическая система FERES

## Обзор

Этот документ описывает полную типографическую систему сайта FERES. Она обеспечивает:

- ✅ **Согласованность** — единая система размеров и весов по всему сайту
- ✅ **Масштабируемость** — математическая шкала размеров (Perfect Fourth, 1.25x)
- ✅ **Семантичность** — правильное использование HTML-тегов без нарушения структуры
- ✅ **Удобство обслуживания** — одна переменная изменяет типографику везде
- ✅ **Доступность** — правильные пропорции, контрастность, читаемость

## Файлы

- **`typography.css`** — полная типографическая система с переменными и классами
- **`feres.css`** — основной CSS файл, подключает typography.css через @import

## Фирменные шрифты

Используется шрифт **FERES** (PF Din Text Cond Pro) в 5 вариантах:

```css
--font-light:    300  /* feres-300.woff2   */
--font-regular:  400  /* feres-400.woff2   */
--font-medium:   500  /* feres-500.woff2   */
--font-bold:     700  /* feres-700.woff2   */
--font-italic:   400i /* feres-400i.woff2  */
```

Основное семейство шрифтов:
```css
--font-brand: 'FERES', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;
```

## Шкала размеров (CSS переменные)

### Заголовки

```css
--fs-h1:     clamp(38px, 7.2vw, 84px)   /* Самый крупный (главный заголовок) */
--fs-h2:     clamp(27px, 3.4vw, 46px)   /* Основной заголовок секции */
--fs-h3:     clamp(20px, 1.7vw, 26px)   /* Подзаголовок */
--fs-h4:     18px                       /* Малый заголовок */
--fs-h5:     16px                       /* Очень малый заголовок */
```

### Текст

```css
--fs-body:       17px  /* Основной размер текста */
--fs-body-sm:    15px  /* Уменьшенный основной текст */
--fs-small:      15px  /* Мелкий текст */
--fs-xs:         14px  /* Очень мелкий */
--fs-micro:      13px  /* Микро текст */
--fs-eyebrow:    12px  /* Вспомогательный */
```

### Высота строк (Line-height)

```css
--lh-tight:   1.1   /* Для заголовков */
--lh-normal:  1.4   /* Для основного текста */
--lh-relaxed: 1.6   /* Для больших блоков */
--lh-loose:   1.8   /* Для максимальной читаемости */
```

### Интерлеттинг (Letter-spacing)

```css
--ls-tight:        -0.01em   /* Для крупных заголовков */
--ls-normal:       0         /* По умолчанию */
--ls-loose:        0.03em    /* Для текста-тага */
--ls-ultra-loose:  0.14em    /* Для UPPERCASE */
```

## Использование: HTML + CSS классы

### ✅ Правильно (используй классы)

```html
<!-- Заголовок h1 с правильным стилем -->
<h1 class="h1">Главный заголовок</h1>

<!-- Если нужен размер h1, но семантика другого тега -->
<h2 class="h1">Выглядит как h1, но семантически h2</h2>

<!-- Основной текст -->
<p class="body">Обычный абзац</p>

<!-- Мелкий текст -->
<p class="small">Мелкий текст</p>

<!-- Вспомогательный текст (eyebrow) -->
<p class="eyebrow">Раздел · название</p>

<!-- Текст-тег -->
<span class="label">КАТЕГОРИЯ</span>
```

### ❌ Неправильно (НЕ используй inline-style)

```html
<!-- Плохо! Нарушает систему -->
<p style="font-size: 16px; line-height: 1.5;">Текст</p>

<!-- Плохо! Нельзя смешивать -->
<h2 class="h1" style="font-size: 20px;">Заголовок</h2>
```

## Пример: создание нового компонента

### Задача: Создать карточку продукта

```html
<!-- HTML — правильно структурирован -->
<div class="product-card">
  <h3 class="h4">Название продукта</h3>
  <p class="small">Краткое описание товара</p>
  <p class="label">КАТЕГОРИЯ</p>
  <p class="body">Полное описание с техническими характеристиками и преимуществами.</p>
</div>
```

```css
/* CSS — используем переменные, НЕ inline-styles */
.product-card {
  padding: 24px;
}

.product-card .h4 {
  /* уже имеет правильные размер, вес, высоту строки */
}

.product-card .small {
  /* уже имеет правильный размер и цвет */
  color: var(--text-2);
}

/* Если нужны особые стили, используй переменные */
.product-card .body {
  line-height: var(--lh-relaxed); /* Переменная, не hardcode */
}
```

## Как изменить типографику глобально

Если нужно изменить размер заголовков ко всему сайте:

```css
/* В typography.css найди переменную и измени её */
:root {
  --fs-h1: clamp(42px, 8vw, 90px);  /* было: 38px, 84px */
  /* Всё перестроится автоматически */
}
```

Никаких поиск-замены по файлам! Всё меняется в одном месте.

## Правила, которых нужно придерживаться

1. **НИКОГДА** не используй `style="font-size: ..."` в HTML
2. **ВСЕГДА** используй классы из `typography.css`
3. **ЕСЛИ** нужна переменная, добавь её в `:root` в typography.css
4. **НЕ** hardcode размеры в компонентных CSS файлах
5. **ПОМНИ**: семантический HTML + классы типографии = идеально

## Интеграция с новыми страницами/компонентами

Когда создаёшь новую страницу или компонент:

1. Подключи основной CSS: `<link rel="stylesheet" href="assets/css/feres.css">`
   - Это автоматически подключит typography.css через @import
2. Используй только классы из этого гайда
3. Если нужна переменная которой нет — добавь в typography.css
4. Тестируй в обоих режимах: свет/темнота, мобильный/десктоп
